# Evaluation Results

This folder is for measured evaluation outputs.

Do not commit private CVs here. Do not edit gold labels after seeing
predictions. Do not claim final metrics unless they were generated from the
evaluation scripts and validated by the team.

Suggested output files:

- `cv_evaluation_results.json`
- `matching_evaluation_results.json`
- `evaluation_summary.md`

Files ending in `.sample.json` are script verification outputs only. They are
not final benchmark results.
