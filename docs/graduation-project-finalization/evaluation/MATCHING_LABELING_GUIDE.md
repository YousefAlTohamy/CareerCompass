# Matching Labeling Guide

This guide keeps job-fit labels and explanation checks consistent.

## Fit Labels

Use three labels:

- High: the user has most core required skills.
- Medium: the user has related skills but visible gaps.
- Low: the job is mostly unrelated or missing core skills.

The label should be assigned by reviewers before looking at CareerCompass match
scores.

## Matched And Missing Skills

For each CV/job pair, label:

- Expected core skills: skills that should strongly influence the match.
- Expected missing skills: important job requirements not present in the CV.
- Reviewer notes: short explanation of why the fit is High, Medium, or Low.

CareerCompass explanations should be checked against these labels:

- Matched skills should overlap with expected core skills.
- Missing skills should include important expected gaps.
- Recommendations should help address real missing skills.

## Score Sanity

The match score is guidance, not a hiring decision. Still, it should behave
sensibly:

- High fit should generally score above Medium and Low.
- Medium fit should generally score above Low.
- Low fit should not receive a misleadingly confident score.
- High-fit examples should tend to have better rank positions.

Use reviewer notes to explain exceptions honestly.
