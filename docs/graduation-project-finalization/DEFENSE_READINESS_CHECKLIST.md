# Defense Readiness Checklist

Use this checklist for the last preparation pass before the CareerCompass
graduation defense.

## Before Defense Day

- [ ] Main branch status is known.
- [ ] Final graduation branch has been reviewed.
- [ ] Docker stack has been tested on the final demo machine.
- [ ] Synthetic or anonymized sample CVs are ready outside git.
- [ ] Demo accounts are ready locally.
- [ ] Screenshots are captured as fallback material.
- [ ] Final smoke test has passed.
- [ ] Presentation is ready.
- [ ] Report draft is ready.

## On Defense Machine

- [ ] Docker Desktop is running.
- [ ] Ports are free: 80, 5173, 8000, and 8003.
- [ ] Browser is ready.
- [ ] Incognito/private window is available.
- [ ] Sample CVs are available locally.
- [ ] Credentials are available outside git.
- [ ] Internet is not required for the core demo.
- [ ] External scraping is not required for demo success.

## Live Demo

- [ ] Student flow works.
- [ ] Admin flow works.
- [ ] Status page works.
- [ ] Failure playbook is available.
- [ ] No fake metrics are visible.
- [ ] No secrets are visible.
- [ ] No private CV data is visible.

## After Defense

- [ ] Tag the final graduation version if desired.
- [ ] Decide whether to continue productization after graduation.
- [ ] Collect examiner and supervisor feedback.
