   what is complete and what remains.

   final preparation pass.

   and keep [demo-assets/DEMO_FAILURE_PLAYBOOK.md](demo-assets/DEMO_FAILURE_PLAYBOOK.md)
   available.
4. Use [FINAL_REPORT_OUTLINE.md](FINAL_REPORT_OUTLINE.md) and
   [PRESENTATION_OUTLINE.md](PRESENTATION_OUTLINE.md) to finalize academic
   submission material.
