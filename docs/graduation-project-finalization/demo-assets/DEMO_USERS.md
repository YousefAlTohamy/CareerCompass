# Demo Users

Use local-only demo accounts for the final defense. Do not commit real
passwords or private credentials.

| Role | Email Placeholder | Purpose |
| --- | --- | --- |
| Student/User | `demo.user@example.test` | CV upload, extracted skills, jobs, recommendations, gap analysis, and applications tracker. |
| Admin | `demo.admin@example.test` | Admin dashboard, users, scraping sources, diagnostics, and health/status checks. |

## Preparation Notes

- Do not commit real passwords.
- Prepare the accounts locally before the defense.
- Verify role permissions before the defense.
- Use memorable local-only credentials during the demo, but keep them outside
  git and outside screenshots.
- Test user and admin flows in separate browser sessions or incognito windows
  so role switching does not waste defense time.
- Confirm the student account has either a fresh upload-ready state or a known
  successful CV analysis available as fallback.
- Confirm the admin account can access dashboard and source diagnostics pages.
