# Sample Jobs Plan

The defense should rely on demo jobs or reliable imported API data. External
public scraping sources should not be required for the live defense. If public
sources are blocked, show that as honest source diagnostics rather than a demo
failure.

## Recommended Job Categories

| Job Category | Required Skills | Backend CV | Frontend CV | Data Analyst CV | Weak CV | Gap Analysis Should Demonstrate |
| --- | --- | --- | --- | --- | --- | --- |
| Laravel Backend Developer | PHP, Laravel, MySQL, REST API, Docker, Git, testing | High | Low | Low | Low | Backend strengths plus missing testing, queues, cloud, or CI/CD skills. |
| React Frontend Developer | JavaScript, React, HTML, CSS, Vite, Tailwind, API integration | Medium | High | Low | Low | Frontend strengths plus missing state management, testing, or backend API depth. |
| Full Stack Developer | Laravel, React, MySQL, REST API, Docker, Git | Medium | Medium | Low | Low | Cross-stack skill gaps and how missing backend/frontend skills affect fit. |
| Data Analyst | Python, SQL, Excel, Power BI, data cleaning, visualization | Low | Low | High | Low | Analyst fit and missing business intelligence or statistics skills. |
| DevOps Engineer | Docker, Linux, CI/CD, monitoring, cloud basics, scripting | Medium | Low | Low | Low | Infrastructure gaps such as CI/CD, monitoring, and cloud operations. |
| AI/ML Engineer | Python, machine learning, data preprocessing, model evaluation, SQL | Low | Low | Medium | Low | ML gaps for non-AI personas and partial fit for data-analysis skills. |

## Demo Guidance

- Use a small set of stable jobs that cover High, Medium, and Low fit cases.
- Prefer demo/API baseline sources for live defense reliability.
- Keep public HTML scraping as an architecture and diagnostics discussion, not
  the only source of jobs during the defense.
- Make sure every selected job has enough required skills to make gap analysis
  meaningful.
- Avoid fake external-source jobs. If demo jobs are used, label them clearly as
  demo/imported data.
