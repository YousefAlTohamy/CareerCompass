# Graduation Demo Assets

This folder contains practical assets and plans for the final CareerCompass
graduation defense demo. It is designed to help the team run a stable,
repeatable academic demonstration alongside the main finalization documents in
`docs/graduation-project-finalization/`.

This folder does not contain private real CVs, passwords, API keys, tokens, or
other secrets. Any real defense credentials should be prepared locally and kept
outside git. Any CV files used in the live demo should be synthetic or fully
anonymized.

## Demo Priorities

The final demo should prioritize:

- Stable user flow from landing page to authenticated student experience.
- CV upload with a synthetic or anonymized file.
- Skill extraction and profile interpretation.
- Job recommendations based on available imported/demo job data.
- Gap analysis through matched and missing skills.
- Application tracking for saved opportunities.
- Admin diagnostics for users, jobs, sources, queues, and health checks.
- Honest source matrix explanation for reliable API/demo sources versus public
  sources that may be blocked.
- Evaluation framework explanation without claiming final metrics unless the
  scripts generated them from labeled data.
