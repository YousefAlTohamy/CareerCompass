# Sample CV Plan

The defense should use synthetic or anonymized CVs only. Do not add actual PDF
files in this phase, and do not include real names, emails, phone numbers, or
private work history in git.

These personas are designed for a repeatable graduation demo and can also be
used later as evaluation-label examples.

## Persona 1: Backend Developer CV

- Expected role: Backend Developer / Laravel Developer.
- Skills: PHP, Laravel, MySQL, REST API, Docker, Git.
- Expected demo result: strong backend match, with visible gaps for testing,
  cloud, CI/CD, or advanced deployment skills depending on the selected job.

## Persona 2: Frontend Developer CV

- Expected role: Frontend Developer / React Developer.
- Skills: JavaScript, React, HTML, CSS, Vite, Tailwind.
- Expected demo result: frontend recommendations, with backend or database gaps
  visible when compared to full-stack or backend roles.

## Persona 3: Data Analyst CV

- Expected role: Data Analyst.
- Skills: Python, SQL, Excel, Power BI, Data Visualization.
- Expected demo result: analyst-related matching, with machine learning gaps if
  compared to an AI/ML Engineer job.

## Persona 4: Weak or Incomplete CV

- Expected role: uncertain or partial.
- Skills: limited; include only a few broad or weakly described skills.
- Expected demo result: partial profile, lower confidence or partial parsing
  behavior, and recommendations to improve the CV or add clearer skills.

## Safety Notes

- Demo PDFs should be synthetic or fully anonymized.
- Keep raw CV files outside git unless they are intentionally synthetic demo
  artifacts approved by the team.
- Avoid showing private personal data in screenshots or recordings.
- Use these personas consistently in the evaluation framework if the team later
  prepares labeled examples.
